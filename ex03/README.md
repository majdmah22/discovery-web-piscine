# Project 00 — Linux, Git & GitHub

## Overview

This project introduces fundamental tools used in modern software development.
It covers Linux terminal basics, Git version control, GitHub remote repositories,
and SSH authentication.

## Project Structure

The project contains exercises that practice:

- Linux terminal navigation
- File and directory management
- Git version control
- GitHub repository management
- SSH authentication

## Why Git Makes Development Easier

Git makes development easier because it keeps track of changes made to a project
over time.

First, Git safeguards code by keeping a history of previous versions. If a new
change causes a problem, developers can return to an earlier working version.

Second, Git tracks history. Each commit records a specific set of changes,
making it easier to understand what was changed and when it was changed.

Third, Git enables team collaboration. Multiple developers can work on the same
project, create branches, review changes, and merge their work without manually
copying files over each other.

GitHub adds remote storage and collaboration features. A local Git repository can
be connected to GitHub so that changes can be pushed to a remote repository and
shared with other developers.

## Git Workflow

The basic Git workflow is:

1. Edit files.
2. Check the repository status.
3. Add changes to the staging area.
4. Commit the changes.
5. Push the commit to the remote repository.

## SSH Authentication

SSH provides a secure method for connecting a local Git repository to GitHub.

An Ed25519 SSH key pair consists of a private key and a public key. The private
key must remain secret, while the public key can be added to GitHub.

Using SSH allows Git operations such as pushing changes without entering a
GitHub password each time.

## Conclusion

Git, GitHub, and SSH provide a reliable foundation for version control,
collaboration, project history, and secure authentication.
